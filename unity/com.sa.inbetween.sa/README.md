# SA Inbetween for SA Animation

Play clips generated by sa-inbetween on an SA shared-family character, without writing a script.

1. Generate a motion: `sa-inbetween generate ... --out walk.saib`
2. Bake it: `dotnet run --project tools/SA.Soma.Bake -- families/humanoid-v1.safamily walk.saib walk.saclip` (sa-motion)
3. Drop `walk.saclip` into `Assets/`. It imports as a `SaClipAsset`.
4. Add `SaClipPlayer` to any GameObject in the scene, assign the clip. It finds the shared-family character, adds the clip to its clip table and plays it.

`SaClipPlayer` needs exactly one shared-family character in the world and reports why it cannot play in `Status`. `Stop()` removes the clip again. `SaClipRuntime.TryAttach/Detach` are the same operations for your own code. Both run on the main thread at a sync point and never inside a system update.

## Inbetween Studio

`Window > SA > Inbetween Studio` makes a motion from a list: choose a start pose and a goal pose, press **Generate motion**, then **Preview on character**. Setup is one folder (see `docs/designer-guide.md` in the sa-inbetween repository). Generation runs in a separate process, so the Editor stays responsive and **Cancel** works. It never runs in an ECS system, and the Studio is an editor tool that is not part of player builds.
